Rust Heli Trainer

Rust の Minicopter 風の操縦をブラウザで練習するための非公式シミュレーター

Rust 言語 + WebAssembly 版 (元の JavaScript 版)

モード

操作 (Rust のデフォルト準拠)

Wスロットル上昇 (上昇)
Sスロットル下降 (降下)
Ctrl押している間は揚力が抜ける (空中なら落ちる)。地上では Ctrl+W で前進 / Ctrl+S で後退 / A・D で向きを変える
A / Dヨー (その場で機首を左右に回す + 旋回方向へ傾く。傾きは自動で戻らないのでマウスで直す)
マウス 前後ピッチ (前傾で前進 / 後傾で減速・後退)
マウス 左右ロール (横に傾けて旋回・横移動)
C / V視点切替 (パイロット / 機内 / コックピット / 近接 / TPS / チェイス / 俯瞰)
Rリスポーン
HHUD 表示 ON/OFF
Esc一時停止 / メニュー

設定

パイロットから何 m 後ろを中心に機体が回るか。大きいほど A/D で前の席が大きく振られる (-0.4 m が以前の挙動)
デフォルト視点とカメラ位置 計器盤の箱: 0% で透明 (メーターだけ残る)。距離・高さはマイナスも可 (前方 / 機体の下)。飛行中はマウスホイールで今の視点の距離を調整できます

HUD 表示 (H で全体を ON/OFF)

Facepunch Studios とは無関係のファンメイド練習ツールです。挙動は本家を近似したもので完全一致ではありません。

PC + マウス推奨。開始するとマウスがロックされます (Esc でこのメニューに戻る)
